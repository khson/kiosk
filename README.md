# 🍳 지우네식당 키오스크

아이와 **식당놀이**할 때 쓰는 태블릿용 주문 키오스크입니다.
설치·서버·빌드 없이 `index.html` 파일 하나로 동작합니다.

## 주요 기능

| 화면 | 기능 |
|---|---|
| 시작 | 🎮 놀이 모드 / ✏️ 공부 모드 선택, 매장 식사 / 포장 선택, 소리 켜기·끄기, 전체 화면 |
| 메뉴 | 한식·중식·일식·양식·분식·음료·디저트 (44가지), 인기·매워요 표시, 품절 표시 |
| 메뉴 고르기 | 맵기·곱빼기·컵 크기·얼음·맛·굽기·부먹/찍먹 옵션, 라면 토핑(떡·계란·치즈, 여러 개 선택), 김밥 종류 7가지, 수량 |
| 주문 확인 | 수량 수정, 매장/포장 변경, 금액을 한글로 읽어주기 (예: 17,000원 → 만 칠천 원) |
| 결제 | 💳 카드(꽂는 애니메이션) / 💵 현금(지폐·동전을 눌러서 내기, 거스름돈 지폐·동전 개수 계산) |
| 주문 완료 | 주문 번호 영수증, 음성 안내, 포춘쿠키 주문 시 오늘의 운세 |
| 주방 (어른용) | 시작 화면의 **주방 버튼을 꾹 누르기**(약 1초)로 진입. 주문 현황, "요리 완료" 시 "N번 손님 음식 나왔습니다" 음성 호출, 판매 금액, 품절 관리, 식당 이름 바꾸기, 주문 번호 초기화 |

## ✏️ 공부 모드 (더하기·빼기 연습)

시작 화면에서 **공부 모드**를 고르면 키오스크가 계산해 주던 부분을 아이가 직접 계산합니다. (고른 모드는 다음에도 유지됩니다)

| 단계 | 문제 | 정답 확인 |
|---|---|---|
| 주문 확인 | **더하기**: 주문한 음식 값의 합계 (예: `7,000 + 7,000 + 3,000 = ?`) | 맞히면 합계와 결제 버튼이 나타남 |
| 현금 결제 | **빼기**: 거스름돈 = 낸 돈 − 주문 금액 (예: `20,000 − 17,000 = ?`) | 맞히면 거스름돈과 "결제 끝" 버튼이 나타남 |

- 숫자 패드(1~9, 0, 000, ⌫)로 답을 입력합니다.
- 틀리면 "정답보다 커요 ⬇ / 작아요 ⬆" 힌트를 보여 주고, 3번 틀리면 "정답 보기" 버튼이 나타납니다.
- 공부 모드에서는 메뉴 화면 합계가 `?원`으로 가려지고, 돈이 모자랄 때도 남은 금액을 알려 주지 않습니다.
- 같은 메뉴를 여러 개 담으면 곱셈 대신 `7,000 + 7,000`처럼 풀어서 더하기로 냅니다. 항이 6개를 넘으면 메뉴별 금액으로 묶습니다.
- 주문 완료 화면에 ⭐ 결과(한 번에 맞힘 ⭐⭐⭐)가 나오고, 주방 화면에서 "한 번에 맞힌 계산 문제" 수를 볼 수 있습니다.

## 참고

- 가격은 모두 500원 단위라 덧셈·거스름돈 계산 연습에 맞춰져 있습니다.
- 주문 기록·품절·식당 이름은 태블릿 브라우저에 저장됩니다(localStorage). 다른 기기와는 공유되지 않습니다.

## 태블릿에서 쓰는 법

1. 이 저장소에서 **Settings → Pages → Branch: main / root** 로 GitHub Pages를 켜면
   `https://khson.github.io/kiosk/` 주소로 열 수 있습니다. (또는 `index.html`을 태블릿에 복사해서 열어도 됩니다)
2. 태블릿 브라우저에서 열고 **홈 화면에 추가**하면 주소창 없이 전체 화면 앱처럼 실행됩니다.
3. 음성 안내는 기기의 한국어 음성(TTS)을 사용합니다. 소리가 안 나면 기기 설정에서 한국어 음성을 확인하세요.

## 메뉴 바꾸기

`index.html` 안의 `MENU` 배열을 고치면 됩니다.

```js
{ id: "bibimbap", cat: "korean", name: "비빔밥", emoji: "🍚", price: 7000,
  desc: "밥에 나물과 고추장을 넣고 쓱쓱 비벼요.", tags: ["인기"], opts: ["spicy"] },
```

- `cat`: `korean` / `chinese` / `japanese` / `western` / `snack` / `drink` / `dessert`
- `tags`: `인기`, `매워요`, `무료` 등 자유롭게
- `opts`: `OPTS`에 정의된 옵션 키 (`spicy`, `big`, `size`, `ice`, `flavor` …)
  - `OPTS`에 `multi: true`를 주면 여러 개 고르는 옵션(예: 라면 토핑), `showTotal: true`를 주면 보기마다 최종 가격이 보이는 옵션(예: 김밥 종류)이 됩니다.
